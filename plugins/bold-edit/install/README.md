# install — Installer V1 (R10)

- `installer.mjs`: install · uninstall · update · status. É Node puro, roda em macOS e Windows.
- `paths.mjs`: caminhos puros (Skill pessoal/projeto, bin dir, estado), parametrizados por SO.
- Wrappers: `../install.sh` (macOS/Linux) e `../install.cmd` (Windows, EXPERIMENTAL).

Documentação: `INSTALL.md` e `references/portability.md`.
